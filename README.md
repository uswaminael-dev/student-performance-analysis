# Student Performance Analysis 📊

## Project Overview
This project explores student academic performance using Python and popular Data Science libraries.

The objective is to understand patterns in student study habits, attendance, and examination marks through data exploration, cleaning, statistical analysis, and visualization.

## Objectives
- Explore and understand a dataset.
- Identify and handle missing values.
- Detect and remove duplicate records.
- Calculate descriptive statistics.
- Analyze relationships between study hours, attendance, and marks.
- Create meaningful data visualizations.

## Technologies Used
- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn

## Project Workflow
1. Dataset creation
2. Data exploration
3. Data cleaning and preprocessing
4. Descriptive statistical analysis
5. Exploratory Data Analysis (EDA)
6. Data visualization
7. Interpretation and conclusions

## Visualizations
The project includes:
- Student performance bar chart
- Marks distribution histogram
- Study hours vs. marks scatter plot
- Correlation heatmap

## Project Files
- `student_analysis.ipynb` – Complete analysis and code.
- `cleaned_student_data.csv` – Cleaned dataset.
- `requirements.txt` – Required Python libraries.

## Key Learning Outcomes
Through this project, I gained practical experience in:
- Working with Jupyter Notebook.
- Manipulating datasets using Pandas.
- Performing numerical operations using NumPy.
- Handling missing values and duplicate records.
- Conducting exploratory data analysis.
- Creating visualizations using Matplotlib and Seaborn.

## How to Run the Project

1. Clone this repository.
2. Install the required libraries:
   `pip install -r requirements.txt`
3. Open the project in VS Code.
4. Open `student_analysis.ipynb`.
5. Run all notebook cells.
